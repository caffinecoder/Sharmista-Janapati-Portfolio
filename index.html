01 / About Project

A production-grade full-stack voice cloning service that ingests a short 3–10 second Telugu audio clip alongside its transcript, producing studio-fidelity speech for any submitted text script. Powered by AI4Bharat's IndicF5 neural model and hosted via persistent Modal volume mounts with asynchronous status polling.

02 / Problem It Solves

Standard inference architectures timeout on HTTP endpoints and exhaust GPU VRAM during lengthy audio rendering. Voice Clone Studio decouples user request loops via background GPU queues, automatically truncating multi-thousand-word inputs into ~50-word syntactic chunks and stitching them with calculated acoustic silence padding.

03 / Challenges Faced & Engineering Breakthroughs

1. Checkpoint Key Mismatch & Flat Audio

Published IndicF5 weights were wrapped in torch.compile(), prefixing keys with _orig_mod.. HuggingFace silently failed key matching, yielding randomly initialized silence. Solved by writing load_checkpoint_with_key_remap() to strip prefixes directly from checkpoint shards.

2. Diagnostic Repeat Testing

Developed debug_repeat_call.py to execute four controlled model invocations on Modal, separating text-content discrepancies from instance weight initialization corruption without guessing.

3. Distributed Modal Job Synchronization

Resolved persistent "Job Not Found" tracking failures across ephemeral container instances by migrating localized dictionaries into universally shared modal.Dict and persistent volumes.

4. Zero-Variance Audio Guardrails

Engineered automated standard-deviation calculations on generated speech buffers to intercept zero-variance silent failures instantly and emit user-facing exceptions.

01 / About & Problem Solved

Raw scraped conversational datasets contain irregular syntactic noise and unstandardized abbreviations that severely degrade downstream text vector embeddings and transformer training efficiency. This tool establishes a reproducible, deterministic token standard prior to modeling.
